Projeto pessoal desenvolvido para a apresentação de um trabalho académico na ETEC Parque Belém, integrando as disciplinas de Programação Web e Língua Portuguesa.

🌐 Acesso Online
Acesse o site diretamente pelo navegador:

👉 https://etecpwprojeto2026.netlify.app

🚀 Destaques
Quiz Aleatório: 10 perguntas e opções (A, B, C, D) embaralhadas a cada tentativa.

Feedback Instantâneo: Respostas corretas e incorretas destacadas na hora.

Interface Responsiva: Funciona em telemóveis, tablets e computadores.

🛠️ Tecnologias
Front-end: HTML5, CSS3 e JavaScript.

Framework & Libs: Bootstrap 5, SweetAlert2, AOS e Canvas Confetti.

📂 Como Rodar Localmente
Baixe o ficheiro .zip mais recente na aba de Releases do repositório.

Extraia o conteúdo do ficheiro .zip no seu computador.

Abra o ficheiro index.html em qualquer navegador.
